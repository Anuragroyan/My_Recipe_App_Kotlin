🍲 Recipe App

Recipe App is a Kotlin-based Android application that allows users to explore food recipes fetched dynamically from an online API. The app is built with Jetpack Compose and follows a modern approach to Android development, combining API integration, asynchronous data handling, navigation, image loading, and ViewModel-based state management.

Recipe data is retrieved from the remote API using Retrofit, while Gson converts the JSON responses into usable application data. Recipe images are loaded efficiently using Coil, and Navigation Compose provides navigation between different screens.

✨ Features

* 🍲 Recipe Listing – Display food recipes retrieved from the online API.
* 🔍 Recipe Exploration – Browse available recipes through the application.
* 🌐 Online API Integration – Fetch recipe data dynamically from a remote API.
* 🔄 Retrofit – Handle REST API communication.
* 📄 Gson Parsing – Convert API JSON responses into Kotlin data.
* 🖼️ Recipe Images – Load remote images using Coil Compose.
* 🧭 Screen Navigation – Navigate between recipe-related screens.
* 🧠 ViewModel – Manage UI state and API-related data.
* ⚡ Dynamic UI – Update the interface based on retrieved recipe data.
* 🎨 Jetpack Compose – Build the modern declarative user interface.
* 📱 Material 3 – Use modern Android UI components.

🎯 Project Purpose

This project demonstrates how to build a real-world API-driven Android application using modern Kotlin development practices. It provides hands-on experience with REST API integration, JSON parsing, ViewModel state management, asynchronous data handling, remote image loading, screen navigation, and dynamic Jetpack Compose UI.
